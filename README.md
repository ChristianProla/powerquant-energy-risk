# PowerQuant

PowerQuant is a Python-based quantitative electricity market analytics,
risk management and forecasting project.

The project simulates quantitative work related to energy trading
and renewable electricity markets.

## Planned features

- Electricity market data API
- Price and return analysis
- Statistical analysis
- Volatility
- Correlation
- Portfolio construction
- Value at Risk
- Expected Shortfall
- Monte Carlo simulation
- Hedge optimization
- Machine learning forecasting
